# 中项网 · 项目详情页 AI 介入原型（前端页面）

工业拟在建项目详情页的「AI 智能介入」弹窗产品原型，纯前端 HTML（零依赖、无外部 CDN），双击即可打开浏览 UI 与交互。

## 页面说明

| 文件 | 内容 |
|---|---|
| `page-detail.html` | 项目详情页模拟（项目跟踪时间轴 / 项目进展 / 项目介绍 / AI 预测采购需求表 / 联系人三分组）。页面内 11 个入口按钮（「AI总结项目重点」「AI分析公司背景及商机」「AI破冰话术」等）点击后右侧滑出抽屉加载弹窗页 |
| `form-match.html` | AI 介入评估弹窗（可独立打开）：结论行 + 三行事实（能不能进 / 什么时候进 / 找谁进）+ 场景化手风琴预置问题 + 自由问答区 |

## 产品设计要点

- **结论先行**：判定卡秒开，定性结论（可以介入/部分相关/暂无明显对口），不放未校准评分
- **每行事实可溯源**：所有数字要么来自源数据、要么标注估算口径（"AI预测·待核验" / "阶段规律·参考"）
- **入口即剧本**：不同入口按钮预填不同种子问题（项目重点 / 公司商机 / KP 话术三组场景）
- **分层数据口径**：事实（实证）直说 / 规律（周期分布）标参考 / 推测（具体日期）不进判定卡

## 本地运行（完整体验含问答）

页面 UI 可直接浏览器打开。弹窗内的 AI 问答依赖后端 SSE 服务（本原型中为 Spring Boot + AgentScope Java，未包含在本仓库）：

```bash
# 在本地 8090 端口跑原型后端后访问
open http://localhost:8090/page-detail.html
```

无后端时打开页面：详情页与弹窗 UI、抽屉交互、预置问题均可正常演示；「发送」问答会提示服务不可用。
